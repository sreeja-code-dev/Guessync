## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability, please follow these steps:

1. "Do not open a public issue."
2. Contact us directly through GitHub DM.
3. Include:
   - A detailed description of the vulnerability
   - Steps to reproduce
   - Potential impact and severity
   - Any suggested mitigation

We aim to respond within "48 hours" and will keep you updated throughout the triage process.

If the vulnerability is confirmed:
- A fix will be developed and tested promptly.
- A security advisory will be published if necessary.
- You may be credited for responsible disclosure (with your consent).

---

##  Security Best Practices

To help contributors and users stay safe:

- Never commit secrets, tokens, or credentials.
- Use HTTPS for all API calls and socket connections.
- Validate and sanitize all user inputs.
- Keep dependencies up to date and audit them regularly.
- Enable 2FA on your GitHub account.

---

## Responsible Disclosure

We appreciate responsible disclosure and will acknowledge contributors who help improve the security of this project. If you're unsure whether something qualifies, reach out anyway—we’d rather over-communicate than miss a risk.
